# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Nexe, please report it privately. Do not open a public issue for security concerns.

You can report vulnerabilities by opening a private security advisory on the GitHub repository or contacting the maintainer directly. Please include:
- A description of the vulnerability and how it can be triggered.
- Potential impact on local file integrity or execution safety.
- Steps or a minimal proof-of-concept to reproduce the issue.

We will review the report promptly and work on a patch.
